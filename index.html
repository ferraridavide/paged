¶Paged Editor GitHub Open the editor

Write print documents on real pages, with React components as your building blocks.

Paged Editor is an open-source editor that runs in your browser. Every element on the page is a React component: use the built-in ones or write your own, style them with CSS, and print or save to PDF.

Open the editor Source on GitHub

Free and open source. No account, no backend, no telemetry.

Pages

What you edit is what prints

You type directly on the page. Edit mode, Preview and print use the same page layout, so line breaks and page breaks stay where you see them.

  • Paragraphs split across pages by line, lists by item, tables by row with the header repeated.
  • A4, A5, Letter or Legal, portrait or landscape, with your own margins.
  • Pages lay out as you type: about 1 to 3 ms per pass on a 67-page test document.
  • Print or save as PDF from the browser's print dialog.

CSS

Style elements with CSS

Give any element classes and style them in the document's CSS. A section of pages can have its own CSS, and each element can have its own styles. The CSS editors have code completion.

  • Styles are scoped to the document, so they never change the editor around it.
  • The more specific context wins: document, then section, then the element itself.
  • Copy and paste styles between elements.
/* Document CSS */
.cover .hd-heading {
  font-size: 40pt;
  color: #312e81;
}

.note {
  border-left: 3px solid #6366f1;
  padding-left: 4mm;
}

Components

Write your own components

When the built-in elements aren't enough, write a React component in the component studio. It is saved inside the document, so the file carries everything needed to render it.

A studio for each component

Code editor with completion, a live preview at page width, controls for each field, problems and console.

npm packages

Pin a package and version, and import it. The sample document uses Chart.js, three.js and a QR code library.

Editable on the page

Fields marked editable are typed into directly on the page. Other props are set in the inspector.

Also included

The rest of a document editor

Sections

A range of pages gets its own size, orientation, margins, header, footer, background and CSS.

Header and footer

The page margins hold any element, including page numbers and the document title.

Formatted text

Bold, italic, underline, strikethrough, font, size, colour and highlight within a paragraph.

Tables and images

Resizable table columns, striped rows, header rows. Images with captions and alignment.

Menus and shortcuts

A menu bar, right-click menus, undo and redo, and keyboard shortcuts for every common action.

Google Drive

Open documents from Drive and save them back. The editor only sees the files you pick.

Your files

Documents stay with you

Paged Editor has no backend. Documents autosave in your browser and save as .pdoc files, a zip with the document, its components and its images. Google Drive is optional.
