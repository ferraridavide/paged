¶ Paged Editor

Privacy Policy

Last updated: November 27, 2026

Paged Editor is an open-source document editor that runs in your browser, at paged.davide.im. The source code is public at github.com/ferraridavide/paged. This policy describes what data the editor handles and where it goes.

Summary

  • Paged Editor has no backend server and no database. The developer does not receive your documents or any information about you.
  • There is no analytics, telemetry, advertising or tracking.
  • Your documents are stored in your browser, in files you save, or in your Google Drive if you choose to use it.

Data stored in your browser

The editor saves the following in your browser's local storage, on your device only:

  • the document you are editing (autosave), including images and custom components in it;
  • editor settings, such as zoom and panel layout;
  • if the document was opened from Google Drive: the Drive file's ID, name, type, folder ID and revision, so that saving updates the same file.

This data is not sent to the developer. You can delete it by clearing this site's data in your browser settings.

Google Drive

Opening and saving documents on Google Drive is optional. If you use it:

  • You sign in with Google in a Google window. Paged Editor does not see your password.
  • Paged Editor asks for the drive.file permission. It can only access files you pick in the Google file picker and files it created for you. It cannot see the rest of your Drive. If the app is installed in Drive's "Open with" menu, it also asks for drive.install, which only adds Paged Editor to that menu.
  • Paged Editor does not request your name, email address or profile picture.
  • Google gives the editor a short-lived access token. It is kept in the page's memory only, is not stored, and is gone when you close the tab.
  • The contents of the files you open are read into your browser. When you save, the document is sent from your browser directly to Google Drive. Nothing goes through a server run by the developer.
  • Data received from Google is used only to open and save your documents. It is not sold, shared, used for advertising, or used to train AI models.

Paged Editor's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

You can remove Paged Editor's access at any time in your Google Account permissions. Google's handling of your data is covered by the Google Privacy Policy.

Other services the editor contacts

Your browser connects to these services directly. Like any website, they receive your IP address and browser information as part of the request. The developer has no access to their logs.

  • GitHub Pages hosts the editor's files. See the GitHub Privacy Statement.
  • esm.sh serves the npm packages that custom components in a document use (for example, the sample document's charts and 3D scene).
  • jsDelivr serves the code editor (Monaco) when you open a CSS or component editor, and answers package searches in the component studio. See the jsDelivr Privacy Policy.
  • Google (accounts.google.com, apis.google.com, googleapis.com), only when you use Google Drive.

Images in a document that point to other websites are loaded from those websites.

Cookies

Paged Editor does not set cookies. Google may set cookies in its own sign-in window.

Children

Paged Editor does not knowingly collect information from anyone, including children.

Changes

If the way the editor handles data changes, this page will be updated and the date above changed. The history of this page is in the public repository.

Contact

For questions about this policy, open an issue at github.com/ferraridavide/paged/issues.
